# 카드 이미지 폴더

선생님께서 준비하실 카드 이미지들을 이 폴더(`public/cards`) 안에 넣어주세요.

## 파일 이름 지정 방식 (확장자는 .png, .jpg 등 통일 권장)
- **a 종류 카드 (번호당 3장씩, 총 12장)**: `a1_1.png`, `a1_2.png`, `a1_3.png` / `a2_1.png`, `a2_2.png`, `a2_3.png` / ... / `a4_3.png`
- **b 종류 카드 (번호당 3장씩, 총 12장)**: `b1_1.png`, `b1_2.png`, `b1_3.png` / `b2_1.png`, `b2_2.png`, `b2_3.png` / ... / `b4_3.png`
- **해골 카드 (1장)**: `x.png`

**규칙 설명**: 이미지는 서로 다르지만(예: `a1_1`과 `a1_2`), 게임 내부적으로는 모두 같은 `a1` 속성으로 취급되어 `b1` 계열 카드(예: `b1_1` 또는 `b1_3` 등) 아무 것과 만나도 짝을 맞출 수 있습니다.

**참고**: 이 폴더는 Vite의 `public` 폴더입니다. 여기에 이미지를 넣으시면 코드에서 복잡한 불러오기 과정 없이 `<img src="/cards/a1_1.png" />`와 같이 바로 화면에 띄울 수 있어 매우 편리합니다.
